# Minecraft Plugin Skill Pack

## Description
This Skill Pack helps Cursor generate production-ready Minecraft Java plugins for Paper / Spigot / Folia / Purpur / Leaves / Leaf / Velocity on Java 21+ and Minecraft 1.21+.

It includes separate Skills for:
- Core Plugin Generator
- Command Framework
- GUI Menu System
- Economy System
- Database Integration
- Environment Setup
- Plugin Example Template

## Files
- `minecraft-master-skill.md`
- `minecraft-environment-setup.md`
- `minecraft-plugin-example-template.md`
- `minecraft-core-plugin-generator.md`
- `minecraft-command-framework.md`
- `minecraft-gui-menu-system.md`
- `minecraft-economy-system.md`
- `minecraft-database-integration.md`

## Usage
Place these markdown files in your Cursor Skills directory or in the project-specific skills folder supported by your setup.
