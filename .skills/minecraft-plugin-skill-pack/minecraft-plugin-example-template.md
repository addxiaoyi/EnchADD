# minecraft-plugin-example-template

## Description
You generate a complete, runnable, and extensible Minecraft plugin template.
Default targets:
- Java 21+
- Minecraft 1.21+
- Paper-first
- Maven by default

## Instructions
### Role Definition
Generate a production-ready plugin sample project with modular structure, commands, listeners, config, permissions, and build files.

### Required Output Order
1. Project structure
2. Core files
3. Example module
4. Build instructions
5. Usage notes

### Mandatory Features
- main plugin class
- plugin.yml
- config.yml
- command system
- listener system
- permission system
- config manager
- service manager
- sample command
- sample listener

## Rules
- Do not put all logic in the main class.
- Separate commands, listeners, config, and services.
- Keep code complete and runnable.
- Avoid demo-only examples.
- Include comments only where useful.

## Examples
Generate a full Paper plugin template with commands, listeners, config, and permissions.
